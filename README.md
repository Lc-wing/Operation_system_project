# CS340 Operating Systems Project

## Project Overview

This is our group project for CS340. We selected Paper 9 and plan to reproduce some of its experiments using LEBench.

Our main goal is to investigate Linux kernel performance by running benchmarks on different kernel versions and comparing the results.

## Week 1 Progress

During the first week, we mainly focused on setting up the experimental environment.

So far, we have:

- Installed Ubuntu 22.04.5 LTS using VirtualBox.
- Installed GCC, Make, and Git.
- Checked the Linux kernel version and system information.
- Created a simple Shell script to check the environment.
- Saved the environment information for later experiments.

We have not started the benchmark experiments yet.

## Project Files

- `scripts/check_environment.sh` – Checks the Linux environment.
- `results/week1-environment.txt` – Stores the environment checking results.
- `docs/week1-environment.md` – Contains our Week 1 progress report.
